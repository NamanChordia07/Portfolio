**Building**

- **[Proofline](https://github.com/NamanChordia07/proofline)**: checks every number an LLM
  writes into a business report against the data, explains how a wrong one is wrong, and
  repairs it. Python library, CI-gating CLI and MCP server. On phrasing it had never seen,
  it caught 98.9–100% of injected errors where a naive "is this number in the data?" check
  caught 16–20%; on a hand-written held-out challenge set it missed no errors on the first
  run. Every result, first runs included, is in the repo.
